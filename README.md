# knowledge-base-manager

# 📝 Knowledge Base App

A full-stack knowledge base application built with **React (TypeScript)** on the frontend and **Node.js + Express** on the backend. Users can create, edit, search, and delete articles stored in a local `articles.json` file.

---

## 📦 Tech Stack

- **Frontend**: React + TypeScript + Vite
- **Backend**: Node.js + Express
- **Storage**: JSON file (`articles.json`)
- **Styling**: CSS

---

## 🚀 Features

- View all articles
- Create new articles
- Edit and update articles
- Delete articles
- Search by keyword (title/content)

---

## ⚙️ Installation & Setup

### 🔧 Prerequisites

Make sure you have the following installed:

- [Node.js (v16 or above)](https://nodejs.org/)
- [npm](https://www.npmjs.com/)
- [Git](https://git-scm.com/)

---

### 📁 Clone the Repository

```bash
git clone https://github.com/your-username/knowledge-base-app.git
cd knowledge-base-app
```

### Backend setup

- cd backend
- npm install
- start the server: node index.js

### Frontend setup

- cd backend
- npm install
- start the frontend: npm run dev
